# JhutPass — demo site

Trust infrastructure for Bangladesh's garment-waste (jhut) economy.
Static, zero-dependency demo: pitch + factory waste simulator + p-median hub map +
BF grading scale + certificate engine. Built for the IPESphere Season 2 Innovation
Challenge prototype demonstration.

Data sources cited on-page (GIZ 2025 via RMG Bangladesh; BGMEA; European Commission
ESPR; Circular Economy & Sustainability 2026; Environ. Sci. & Pollution Research 2026).
